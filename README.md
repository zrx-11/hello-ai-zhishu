# Hello, AI · 人工智能导论 · 知枢学习系统

上海交通大学 AI+ 教育平台《Hello, AI · 人工智能导论》的整书零基础学习系统。单文件总入口 `index.html`，手机和电脑都能直接打开；也可整套推到 GitHub Pages。

**线上站点**：https://zrx-11.github.io/hello-ai-zhishu/  
**仓库**：https://github.com/zrx-11/hello-ai-zhishu

## 这是什么

- **整书覆盖**：14 章正文 + 6 篇专题 + 110 条术语。
- **零基础转译**：不照搬原文，逐章重写成「一句话核心 → 白话讲解 → 图示 → 类比 → 实例 → 常见误解 → 自测 → 复习锚点」。
- **两条教学通道**：20 个章节页 + 50 个概念页；10 个高难概念另附「第一性原理深度推导」，默认折叠。
- **完整记忆系统**：60 道综合单选、100 道章节自测、70 张抽认卡、110 条术语、模式库与速查表。
- **诊断倒推**：答错时沿前置依赖链回溯，告诉你真正该补的是哪一章、哪个概念。
- **移动端适配**：390px 视口正文左右各 18px 内边距，表格不横向溢出，目录限高滚动。

## 怎么用

1. 双击 `index.html`。顶部选书，左侧按「学习路径 → 章节 → 概念 → 测验 → 抽认卡 → 术语 → 模式库 → 速查表」推进。
2. 每章先读「一句话核心」，再读讲解；读完做自测，答错看解析。
3. 高难概念页底部有「🔬 展开完整第一性原理推导」，卡住时展开。
4. 用「🩺 诊断测试」随机抽 5 题，答错会列出前置根因链接。
5. 抽认卡按次日、3 天、7 天复习；进度与卡片状态存在浏览器本地。

## 部署 GitHub Pages

```bash
# 1. 解压本包，进入目录
cd HelloAI学习系统

# 2. 关联仓库（仓库需先在 GitHub 建好，或使用已有仓库）
git init
git remote add origin https://github.com/<用户名>/<仓库名>.git

# 3. 推送
git add -A
git commit -m "Hello AI 知枢学习系统"
git push -u origin main
```

然后在仓库 **Settings → Pages → Deploy from a branch → main → / (root)** 保存。访问：

```
https://<用户名>.github.io/<仓库名>/
```

`.nojekyll` 已放在根目录，中文目录名和 `_work/` 下的下划线文件不会被 Jekyll 处理。

- `verify_handbook.py` 端到端 20/20 通过：首页、书卡、首末章、60 题测验与解析、抽认卡翻转、术语过滤、全局搜索、进度持久、诊断页、出处脚注、深色模式、控制台零错误。
- 深度片段实测：概念页存在 `details.depth-fragment`，展开后正文约 3,100 字符；KaTeX 在该页渲染 55 个公式元素。
- Mermaid 实测：章节页生成 1 个 SVG，CDN 多源与超时回退生效。
- 移动端实测：390px 视口 `.main` 左右各 18px 内边距，页面无横向滚动，表格无溢出。
- 打包后已解压到独立目录冒烟：首页、总览、专题页、测验作答、390px 移动端均通过，详见 `交付说明.md`。

## 已知边界

- 公式与 Mermaid 依赖 CDN；完全离线时公式显示源码、图显示代码块，文字与导航不受影响。
- 深度推导是教学性重构，不是原书逐字复制；数值算例可自行复核。
- 测验与卡片是学习辅助，不替代原书习题与课堂讨论。

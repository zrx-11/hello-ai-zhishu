# 速查表

## 核心公式与规则

| 场景 | 内容 |
|---|---|
| A* 评价函数 | $f(n)=g(n)+h(n)$；$h$ 不高估时保证最短路 |
| 监督学习损失 | $L=\frac{1}{n}\sum_i(\hat y_i-y_i)^2$ |
| 梯度下降 | $w\leftarrow w-\eta\nabla L(w)$ |
| 精确率 | $TP/(TP+FP)$，误报代价 |
| 召回率 | $TP/(TP+FN)$，漏报代价 |
| 注意力打分 | $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$ |
| 缩放定律 | $L(x)=L_\infty+a x^{-b}$ |
| 训练算力估算 | $C\approx6ND$ |
| 扩散前向 | $x_t=\sqrt{\alpha_t}x_0+\sqrt{1-\alpha_t}\epsilon$ |
| 扩散训练目标 | 预测噪声 $\epsilon$，损失 $\|\epsilon-\epsilon_\theta(x_t,t)\|^2$ |
| 奖励模型损失 | $-\log\sigma(r(x,y^+)-r(x,y^-))$ |
| RLHF 目标 | 奖励减去 KL 惩罚：$r-\beta\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$ |
| 余弦相似度 | $\cos(a,b)=a\cdot b/(\|a\|\|b\|)$ |

## 概念对照

| 容易混 | 区别 |
|---|---|
| 参数量 vs 数据量 | 参数是模型容量，数据是学习材料；固定算力下要按比例增长 |
| 预训练 vs 微调 | 预训练学语言与世界，微调改行为与格式 |
| RLHF vs DPO | RLHF 用奖励模型 + 强化学习；DPO 直接优化偏好对 |
| 幻觉 vs 错误 | 幻觉是自信地编造看似合理的内容；错误也可能是算错、看错 |
| RAG vs 微调 | RAG 改回答时看到的材料；微调改模型行为 |
| 开放权重 vs 开源 | 开放权重给参数；开源还要求代码、数据、可复现 |
| 识别 vs 预测 | 识别判断「是什么」；预测估计「会怎样」 |
| 生成 vs 决策 | 生成造内容；决策选行动并承担后果 |
| 过拟合 vs 欠拟合 | 过拟合训练好验证差；欠拟合两者都差 |
| 分布偏移 vs 过拟合 | 偏移是部署数据变了；过拟合是模型背了训练噪声 |

## 判断流程

1. 这个任务属于识别、预测、生成还是决策？
2. 数据够不够？标签从哪来？会不会泄漏？
3. 傻基线是什么？多好算好？
4. 错了代价是什么？可逆吗？谁承担？
5. 需要检索、工具、人工确认中的哪几项？
6. 怎么验证？测试集是否只考一次？
7. 部署后怎么监控漂移？

## 成本量级

| 做法 | 数据 | 算力 | 量级 |
|---|---|---|---|
| 提示/技能 | 无 | 推理 | 几乎零成本 |
| RAG | 文档库 + 向量索引 | 推理 + 检索 | 几百到几万元 |
| 微调 | 几千到几万条示例 | 几块 GPU | 几千元级 |
| 中等预训练 | 几十到几百亿 token | 几十块 GPU | 几万元级 |
| 前沿预训练 | 几万亿 token | 几万块 GPU | 几亿到几十亿元 |

## 术语速记

- **Token**：模型读写的最小单位，不等于字或词。
- **嵌入**：把 token 变成连续向量。
- **注意力**：每个位置按相关度从其他位置收集信息。
- **残差**：给梯度一条直路，让深网络可训练。
- **校准**：说 80% 把握时，实际是否约 80% 正确。
- **接地**：陈述要有可追溯依据。
- **驾具**：模型外面的上下文、工具、权限、验证、交付系统。
- **沙盒**：把执行限制在隔离环境里。
- **长尾**：极少出现却可能致命的罕见场景。

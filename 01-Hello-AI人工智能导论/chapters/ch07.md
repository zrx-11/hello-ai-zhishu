# 第 7 章：文字怎样变成数字

> 第三部 · 语言　·　大语言模型从来没有见过一个「字」。它见到的是 token，处理的是向量。

- **难度**：★★☆ ｜ **预估学时**：2 小时 ｜ **前置**：第 6 章

## 学习目标

学完本章，你能：

- 能解释语言模型是一个「下一个 token」的概率分布。
- 能说清分词、BPE、词表和上下文窗口怎样影响模型的行为与成本。
- 能理解词向量、嵌入和余弦相似度，以及它们为什么会继承语料偏见。

## 一句话核心

文字先被切成 token，再变成向量；模型的一切「语言能力」都建立在这两步转换之上，很多怪行为也源于此。

## 零基础讲解

### 概念 1：语言模型是一个概率分布

**语言模型**的定义七十年没变：给定前面的文字，对「下一个词是什么」的每种可能给出概率。翻译、写作、问答，都可以化归为「最可能的续写」。

这个定义听起来窄，实际上很宽。要预测「法国的首都是」后面是什么，模型必须记住地理；要预测一段代码的下一行，它必须理解语法和逻辑；要预测一个故事的结尾，它必须追踪几十页前埋的线索。预测下一个词，是所有语言任务的公分母。

### 概念 2：分词与 token

模型不直接读字。它先把文本切成**token**，也就是模型词表里的基本单元。常见词可能是一个 token，生僻词被拆成几个片段，任何字符最终都能拆到字节。

**BPE（字节对编码）**是最常用的分词方法：从单个字节开始，反复把语料里最常相邻出现的两个单元合并成新单元，进行几万到几十万次，得到词表。它在「词表小」和「单元有意义」之间取一个由数据决定的平衡，对新词适应力强。

分词决定了模型的「视力」。问它「strawberry 里有几个 r」，很多模型会答错，因为它看到的是两三个编号，字母 r 不是一个独立存在的东西。中文还有成本问题：主流词表多在英文语料上构建，很多汉字要占两三个 token，同样一段话的中文版可能比英文版更贵。

**上下文窗口**是模型一次能看到的 token 上限，从几千到上百万。超出部分模型看不见；窗口内的中间部分也常比开头结尾受到更少注意。窗口不是记忆，对话结束后模型什么都不记得。

### 概念 3：词向量与嵌入

每个 token 对应一串数字，叫**词向量**，几百到几千维。这些数字由训练得到：用法相似的词，向量在空间里靠近；意义关系对应方向。经典的例子是：

$$\text{国王} - \text{男人} + \text{女人} \approx \text{女王}$$

**嵌入**是更一般的说法：把离散对象（token、图片、用户、商品）映射到连续向量空间。语义搜索、推荐、检索增强生成、图文互搜，都建立在「把不同东西嵌入同一空间再比较」之上。

比较两个向量最常用**余弦相似度**：看夹角的余弦，方向一致为 1，垂直为 0。它反映的是训练语料里的共现关系。语料里有偏见，向量就会忠实地编码偏见。

## 类比与实例

- **类比**：分词像把一句话拆成乐高积木。常见词是一块大积木，生僻词由几块小积木拼成。模型只认积木的编号，不认积木上写的字母。
- **实例**：「strawberry」在词表里可能被切成 [straw, berry] 两三个 token。模型要数 r，就得从 token 编号间接推断字母，所以经常数错。这不是它笨，是它的输入粒度太粗。

## 常见误解

- 别以为 模型是一个字一个字读的——实际上 它读的是 token，一个 token 可能是一个词、一个片段，甚至几个字节。
- 别以为 上下文窗口就是模型记忆——实际上 窗口只是这次调用能看到的范围，对话结束就没了；真正的持久记忆要靠外部文件或数据库。
- 别以为 词向量是人工标注的——实际上 它是训练出来的，语义关系来自语料共现，因此会继承语料里的偏见。
- 别以为 中文和英文成本一样——实际上 分词器多在英文语料上构建，中文往往占更多 token，成本和速度都可能不同。

## 自测题（答案）

1. 语言模型的定义是什么？（答案：给定前面的文字，对下一个词（token）的每种可能给出概率。；解析：翻译、写作、问答都可化归为条件续写。）
2. BPE 的基本做法是什么？（答案：从单个字节开始，反复合并语料里最常相邻出现的两个单元，直到达到预定词表大小。；解析：它在词表大小和单元意义之间取平衡。）
3. 为什么模型会数错 strawberry 里的 r？（答案：它看到的是 token 编号，字母不是独立单位，需要间接推断。；解析：分词粒度决定了它在拼写、数字母类任务上的弱点。）
4. 上下文窗口是不是模型的长期记忆？（答案：不是。它只是一次调用能看到的 token 范围，对话结束后不保留。；解析：持久记忆需要外部存储。）
5. 余弦相似度衡量什么？（答案：两个向量方向的一致性，1 表示同向，0 表示垂直。；解析：它支撑语义搜索、推荐和 RAG。）

## 复习锚点

- 语言模型 = 下一个 token 的概率分布。
- 分词决定模型看见什么，也决定中文成本。
- 词向量把语义变成几何，但会继承语料偏见。
